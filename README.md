# เว็บเซอร์ไพรส์วันครบรอบ

เปิดไฟล์ `index.html` ในเบราว์เซอร์ (ดับเบิลคลิกได้เลย)

## แก้เนื้อหา

เปิด `config.js` แล้วใส่:

- ชื่อเธอ / ชื่อเรา
- วันที่เริ่มคบ (`YYYY-MM-DD`)
- จดหมาย, เส้นเวลา, ข้อความปิดท้าย

## รูปบนปุ่มเปิดจดหมาย

วางไฟล์ `photos/seal.jpg` แล้วรูปจะถูกครอปเป็นหัวใจบนตราประทับ  
หรือแก้พาทใน `config.js` ที่ `sealPhoto`

## ใส่เพลง

วางไฟล์ในโฟลเดอร์ `music/` ชื่อ `01.mp3` ถึง `05.mp3`  
หรือแก้รายการใน `config.js` ที่ `songs` (title / artist / src)

หลังกดหัวใจ จะมีหน้าต่างเลือกเพลงแบบสไลด์ก่อนเปิดจดหมาย

## มินิเกมปลดล็อครูป

แต่ละรูปมีคำถามใน `config.js` (`question`, `choices`, `answer`)
ทายถูกแล้วรูปจะปลดล็อก และข้อความใน `popups` จะเด้งขึ้นมาหลายครั้ง

## ใส่รูป

คัดลอกรูปไปที่โฟลเดอร์ `photos/` ตั้งชื่อ `01.jpg` `02.jpg` `03.jpg` (หรือแก้ชื่อใน `config.js`)

## ใส่เพลง

วางไฟล์ `music.mp3` ไว้ข้าง `index.html` แล้วกดปุ่ม ♪ มุมขวาล่างหลังเปิดจดหมาย
